Local Dictation @VERSION@

Offline Korean and English dictation. Press a shortcut, speak, and the text appears at your cursor in whatever application you are using.

Audio and transcripts never leave this computer.

Two things happen after installing

  • Install a speech model. Models are not included — they are several gigabytes and carry their own licence. One command downloads one; the next screen has it.
  • Grant Accessibility permission. macOS requires it before any application can register a global shortcut or type into another app.

Local Dictation also needs Python 3.11 or newer to run its speech server on this computer. If you do not have it, install it from python.org or with brew install python.
