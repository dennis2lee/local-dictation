# Local Dictation protocol

Versioned definitions of the client/server contract. Every wire change lands in a
new `vN/` directory; a server never silently reinterprets an older version.

| Version | Status  | Directory        |
| ------- | ------- | ---------------- |
| 1       | current | [`v1/`](v1)      |

The client sends `protocol_version` in its `start` message. A server that does not
implement that version replies with `error.code = "protocol_unsupported"` and closes.

- Wire description: [`v1/protocol.md`](v1/protocol.md)
- JSON Schemas: [`v1/schema/`](v1/schema)

Language bindings generated by hand from these documents live in:

- Python — `server/app/protocol/events.py`
- Go — `client/internal/protocol/events.go`

Both bindings are covered by tests that validate against the schemas in this
directory, so the three copies cannot drift apart silently.
