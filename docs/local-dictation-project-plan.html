01

프로젝트 개요

Local Dictation은 마이크 음성을 외부 클라우드로 보내지 않고 내부 CPU 서버에서 처리한 뒤, 사용자가 현재 작업 중인 애플리케이션의 커서 위치에 결과를 직접 입력하는 데스크톱 도구다.

ACTIVATIONCtrl + Shift + M한 번 누르면 시작, 다시 누르면 종료하는 전역 토글
MODELlarge-v3한국어·영어 서버 모두 정확도 우선 모델 사용
COMPUTECPU INT8NVIDIA GPU 없이 faster-whisper 기반 추론
CLIENTWindows + macOSGo 공통 코어와 OS별 텍스트 입력 어댑터

핵심 사용자 가치

Privacy

오디오와 전사문이 폐쇄망을 벗어나지 않으며 기본 설정에서 저장되지 않는다.

Direct input

별도의 문서로 복사하지 않고 활성 입력란의 커서 위치에서 partial과 stable 결과를 다룬다.

Bilingual control

자동 언어 감지 대신 한국어·영어 전용 서버를 분리해 결과의 일관성과 운영 가시성을 높인다.

사용자가 어느 애플리케이션에서든 단축키를 눌러 말하고, 현재 커서에서 결과를 확인하며, 정지 시 최종 문장이 안전하게 확정되는 경험을 제공한다.

데이터 흐름

  1. Session open선택한 언어에 따라 한국어 또는 영어 포트에 WSS 세션을 생성한다.
  2. Audio stream클라이언트가 선택된 마이크에서 16 kHz mono PCM 프레임을 20~40 ms 단위로 전송한다.
  3. Incremental decode서버가 VAD와 누적 버퍼를 이용해 large-v3를 반복 실행하고 결과의 안정 접두사를 계산한다.
  4. Cursor compositionpartial은 수정 가능한 조합문자로 표시하고, stable 접두사는 확정한다.
  5. Flush and close두 번째 단축키 입력 시 남은 오디오를 처리하고 final을 확정한 뒤 연결을 종료한다.
04

Python 서버 설계

동일한 서버 코드와 모델 파일을 사용하되, 언어와 포트만 다른 두 프로세스를 독립적으로 운영한다.

API

FastAPI와 Uvicorn으로 health, readiness, WebSocket 엔드포인트를 제공한다.

Inference

faster-whisper의 large-v3, device=cpu, compute_type=int8를 사용한다.

Streaming

Silero VAD와 안정 접두사 정책으로 partial과 stable을 구분한다.

언어별 프로세스

서비스언어기본 포트모델역할

성능 운영 원칙

  • 서버 시작 직후 짧은 샘플로 모델 워밍업을 수행한다.
  • 각 프로세스의 CPU affinity와 thread 수를 물리 코어 기준으로 벤치마크한다.
  • 동시 세션 수를 제한하여 과부하 시 무한 대기 대신 명시적 server_busy 오류를 반환한다.
  • 고정된 모델 로컬 경로만 사용하고 인터넷 자동 다운로드를 금지한다.
  • 오디오와 전사문은 기본적으로 디스크에 기록하지 않는다.

06

클라이언트–서버 통신 규격

텍스트 제어 이벤트는 JSON, 오디오는 WebSocket binary frame으로 전송한다. 프로토콜 버전을 명시해 호환성을 관리한다.

start
세션 ID, 프로토콜 버전, 오디오 형식, 클라이언트 버전을 전달한다.
audio
16 kHz mono signed 16-bit little-endian PCM binary frame.
transcript
revision, stable, partial, final을 반환한다.
flush
클라이언트가 캡처 종료 후 남은 결과의 확정을 요청한다.
error
호환성, 과부하, 오디오 형식, 추론 실패 코드를 전달한다.
불변 조건

stable은 한 세션 안에서 단조 증가하며 이미 확정된 접두사는 변경하지 않는다. 오래된 revision은 클라이언트가 폐기한다.

사용법

최초 설정과 일상 사용 흐름을 분리해 교육 부담을 최소화한다.

최초 설정

  1. Open Settings트레이에서 Local Dictation을 열고 Settings 탭을 선택한다.
  2. Configure serversServer address, Korean port, English port를 입력하고 Test connections를 실행한다.
  3. Select microphone사용할 장치를 고르고 Test microphone으로 입력 레벨을 확인한다.
  4. Save설정을 저장한다. OS에서 마이크와 접근성 또는 입력기 권한을 허용한다.
  5. Check update필요하면 Check for updates로 내부 배포 서버의 새 버전을 확인한다.

일상 받아쓰기

  1. Place cursor메일, 문서, 채팅 등 입력할 위치에 커서를 둔다.
  2. Select languageMain 탭에서 Korean 또는 English를 선택한다.
  3. StartCtrl + Shift + M을 눌러 녹음을 시작한다. partial이 커서에 나타난다.
  4. Speak naturallystable로 확정된 부분은 유지되고 partial 영역만 새 결과로 교체된다.
  5. StopCtrl + Shift + M을 다시 누르면 final 결과를 기다린 후 세션이 종료된다.

server/app/api.py
from fastapi import FastAPI, WebSocket, WebSocketDisconnect

app = FastAPI(title="Local Dictation Server")

@app.get("/health/ready")
async def ready():
    return {"status": "ready", "language": settings.language}

@app.websocket("/v1/dictation")
async def dictation(ws: WebSocket):
    await ws.accept()
    session = streaming.create_session()
    try:
        while True:
            message = await ws.receive()
            if chunk := message.get("bytes"):
                event = await session.push_audio(chunk)
                if event:
                    await ws.send_json(event)
            elif message.get("text"):
                await handle_control(ws, session, message["text"])
    except WebSocketDisconnect:
        await session.close()

Go: 언어별 포트 선택과 세션 시작

client/internal/session/controller.go
func (c *Controller) Start(ctx context.Context, language Language) error {
    if !c.state.CompareAndSwap(Idle, Connecting) {
        return ErrSessionBusy
    }

    port := c.config.KoreanPort
    if language == English {
        port = c.config.EnglishPort
    }
    endpoint := fmt.Sprintf("wss://%s:%d/v1/dictation", c.config.Host, port)

    conn, _, err := websocket.Dial(ctx, endpoint, c.dialOptions())
    if err != nil {
        c.state.Store(Error)
        return err
    }
    c.state.Store(Listening)
    return c.run(ctx, conn, language)
}

Go: stable/partial 적용

client/internal/input/composer.go
func (c *Composer) Apply(event TranscriptEvent) error {
    if event.Revision <= c.lastRevision {
        return nil // discard stale server event
    }
    if !strings.HasPrefix(event.Stable, c.committed) {
        return ErrStablePrefixChanged
    }

    stableDelta := strings.TrimPrefix(event.Stable, c.committed)
    if stableDelta != "" {
        if err := c.platform.Commit(stableDelta); err != nil { return err }
        c.committed = event.Stable
    }
    if err := c.platform.SetMarkedText(event.Partial); err != nil { return err }
    c.lastRevision = event.Revision
    if event.Final { return c.platform.FinishComposition() }
    return nil
}

보안과 운영

폐쇄망이라는 전제를 코드와 운영 정책 양쪽에서 강제한다.

네트워크·인증

  • WSS와 사내 CA 인증서 사용
  • 가능하면 mTLS로 관리 단말만 허용
  • 서버 인바운드는 두 포트와 health 경로만 허용
  • 서버 인터넷 egress 차단
  • 세션·오디오 크기·연결 수 제한

데이터 보호

  • 오디오·전사문 비저장 기본값
  • 로그에 내용 대신 지연·오류·익명 세션 ID만 기록
  • 메모리 버퍼는 세션 종료 즉시 폐기
  • 비밀번호 필드에서는 받아쓰기 차단
  • 포커스 변경 시 partial 취소 또는 안전 종료

공급망

  • 모델과 패키지를 사내 저장소에 미러링
  • 모델·컨테이너·설치 파일의 SHA-256 검증
  • Python lockfile과 Go module checksum 고정
  • Windows·macOS 배포물 코드 서명

업데이트

  • 외부 인터넷이 아닌 내부 update manifest 확인
  • manifest와 설치 파일의 디지털 서명 검증
  • 사용자 승인 후 설치
  • 업데이트 실패 시 기존 버전 유지·롤백

완료 기준

아래 항목이 모두 충족되어야 첫 운영 버전을 완료로 판단한다.

  • Ctrl + Shift + M이 Windows와 macOS에서 앱 포커스와 무관하게 시작·정지를 토글한다.
  • 선택한 Korean/English 라디오 버튼에 따라 올바른 포트에 연결한다.
  • partial은 커서에서 교체 가능하고 stable/final은 중복 없이 확정된다.
  • 마이크를 선택하고 입력 레벨 테스트를 실행·중지할 수 있다.
  • 두 서버의 연결 상태가 별도 LED로 정확히 표시된다.
  • 서버가 large-v3 CPU INT8로 실행되며 언어가 ko/en으로 고정된다.
  • 관리 명령으로 두 서버를 개별 또는 동시에 시작·종료·조회할 수 있다.
  • 오디오와 전사문이 기본 로그나 디스크에 저장되지 않는다.
  • 네트워크 단절·서버 오류·포커스 변경 시 partial이 안전하게 정리된다.
  • 서명된 내부 업데이트를 확인하고 실패 시 기존 버전을 유지한다.
  • 정의된 앱 호환성 목록과 성능 목표를 파일럿 환경에서 검증한다.
최종 결정 사항

앱 이름은 Local Dictation, 클라이언트는 Go, 서버는 Python, 모델은 Whisper large-v3, 추론은 CPU INT8, 서버는 한국어와 영어 두 프로세스, UI는 영어, 클라이언트는 Windows와 macOS를 지원한다.
